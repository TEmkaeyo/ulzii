02 / Технологийн шийдэл

Хэрхэн бүтээсэн бэ?

ЕБС-ийн сургалтын онцлогт тохируулан, хамгийн сүүлийн үеийн game engine технологид суурилсан.

Bl

3D орчны загварчлалBlender → Unreal Engine 5

Лабораторийн тоног төхөөрөмж, шил сав, багажийг бодит мэт загварчилж UE5-д импортолсон.

Ni

Визуал эффектNiagara Particle System

Хариу урвал, асгаралт, өнгө солигдох, буцлах (NS Bubbles), дулааны уур (NS Steam)-ыг реалистикаар дүрсэлсэн.

Bp

Логик програмчлалBlueprint Visual Scripting

Текстэн код бичихгүйгээр зангилаа (node) системээр интерактив үйлдэл, туршилтын логикийг уян хатан шийдсэн.

Lt

Шугаман хяналтLine Trace / Raycasting

Харах чиглэлийн объектыг илрүүлж, лазер термометрээр хуруу шилний температурыг бодит цагт уншина.

Dt

Өгөгдлийн менежментData Table

Бодисын мэдээлэл, дөлний өнгийг (Flame Color) хатуу кодгүйгээр хүснэгтээр удирдсан.

Ui

Аюулгүй байдлын Label UIBillboard Name Tag

Хөвөгч Name Tag-аар бодисын мэдээлэл, аюулгүй байдлын санамжийг харуулж, бодис андуурахаас сэргийлнэ.
